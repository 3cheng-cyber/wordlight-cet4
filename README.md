# 词间 · Wordlight

给重新开始准备 CET-4 的安卓用户：从五分钟的哲理小问题开始，认词、听音，再写一句自己的英文。

## 手机使用

1. 用手机浏览器打开私人站点，可通过已有 ChatGPT 账户访问；工具无需 Google 账号或 Google 插件。
2. 在浏览器菜单选择“添加到桌面”或“安装应用”。
3. 设置中等待“页面和词库已准备好离线使用”，点击“下载离线音频”。下载可补齐中断项，约 29 MB。下载后支持离线打开、听单词、造句和保存进度。
4. 选择 5 / 15 / 30 / 60 分钟开始。写到一半退出、切换标签或暂停，草稿和步骤保存在本机。
5. 要自动批改，在设置密码框输入自己的 DeepSeek API 密钥。密钥仅保存在当前页面内存；关闭后重新输入。离线句子进入待批改队列，联网且设置密钥后按顺序处理。API 可能收费。
6. “句子本”保存原句、纠正、原因、原始日期和重做状态，可导出错句文本。“足迹”支持导出、导入学习备份。
7. 提醒通过下载并导入手机日历文件实现。请在 OPPO 日历检查通知权限；网页关闭时不承诺后台自行唤醒。

## 内容与学习规则

- 5,358 个去重参考词条：ECDICT 的 cet4 / gk / zk 标签并集，去除 3 个噪声或错误重复词形，并修正少数基础释义。包含基础词与四级参考词；不冒充已与官方大纲逐条核对的完整词表。
- 60 张原创哲理卡片、89 个示范用法；其他词使用词典释义与个人造句提示。词典释义组未全部人工拆成独立义项，人工哲理卡片优先。
- 5,358 条单词发音、89 条例句发音，本机 Microsoft Zira Desktop 美音合成；共 5,447 个 MP3。
- 阅读、听音、造句分别记录。待批改不算答错或掌握；造句词义与基础语法均正确才通过。
- 优先错句和到期复习，再加入新词；每日新词上限默认 10，可调整。连续两次答错插入曾答对的基础词；最近五次错三次，暂停这轮后续新词。
- 答对后的间隔依次为 1 / 3 / 7 / 14 / 30 / 60 天，答错提前至一分钟后可复习。这是可运行的初始间隔策略，不是对每个人遗忘时间的精确预测。
- 连续三个完整自然日没有学习，重新安排中断周学过的词，保留历史进度和错句。
- 考试日默认 2026-12-12，可更改。词库规模不代表以每天五分钟即可在考前完成全部掌握；按实际表现增加时间。

## 数据与隐私

所有学习记录只存本机 IndexedDB，不提供自动跨设备同步。更换手机、卸载浏览器、清除网站数据前先导出备份。浏览器可能因空间不足回收缓存，下载音频后申请持久化存储，但最终行为由系统决定。

DeepSeek 批改通过同源服务端转发；每次请求携带当前内存中的密钥，仅转发目标词、词义和句子。代码不记录或持久保存密钥与句子；不会将密钥打包进网页、备份、源代码或离线缓存。真人账号密钥尚未提供，因此自动化验证使用模拟 API，未产生真实 API 费用。

词典许可见 public/ECDICT-LICENSE.txt；提取版本、具体修订见 public/sources.json。官方大纲入口：https://cet.neea.edu.cn/html1/folder/16113/1588-1.htm 。音频生成记录见 public/audio-manifest.json。

## 开发与验证

Node.js >=22.13，npm 锁定依赖。`npm run install:ci` 安装，`npm run dev` 预览，`npm test` 验证学习逻辑与批改错误处理，`npx tsc --noEmit` 类型检查，`npm run build` 构建 Worker 与完整离线清单，`npm start` 本地运行生产构建。

构建使用 Vinext / React / Cloudflare Workers。`scripts/make-offline-assets.mjs` 必须在框架构建后运行，自动纳入最终 JS/CSS 资源并更新 Service Worker。`public/sw.js` 只缓存页面与静态资源，不缓存批改请求。部署时保留 `.openai/hosting.json` 的既有项目 ID 与私人访问权限。

不包含 Google 插件，不依赖 OpenAI API 密钥。
