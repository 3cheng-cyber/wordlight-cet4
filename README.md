# 词间 · Wordlight

给重新开始准备 CET-4 的安卓用户：从五分钟的哲理小问题开始，认词、听音，再写一句自己的英文。

## 手机使用

1. 用手机浏览器打开私人站点，可通过已有 ChatGPT 账户访问；工具无需 Google 账号或 Google 插件。
2. 在浏览器菜单选择“添加到桌面”或“安装应用”。
3. 设置中等待“页面和词库已准备好离线使用”，点击“下载离线音频”。下载可补齐中断项，约 33 MB。下载后支持离线打开、听单词、造句和保存进度。
4. 选择 5 / 15 / 30 / 60 分钟开始。写到一半退出、切换标签或暂停，草稿和步骤保存在本机。
5. 要自动批改，在设置密码框输入自己的 DeepSeek API 密钥。密钥仅保存在当前页面内存；关闭后重新输入。离线句子进入待批改队列，联网且设置密钥后按顺序处理。API 可能收费。
6. “句子本”保存原句、纠正、原因、原始日期和重做状态，可导出错句文本。“足迹”支持导出、导入学习备份。
7. 提醒通过下载并导入手机日历文件实现。请在 OPPO 日历检查通知权限；网页关闭时不承诺后台自行唤醒。

## 内容与学习规则

- 5,358 个去重参考词条：ECDICT 的 cet4 / gk / zk 标签并集，去除 3 个噪声或错误重复词形，并修正少数基础释义。包含基础词与四级参考词；不冒充已与官方大纲逐条核对的完整词表。
- 60 张原创哲理卡片、89 个示范用法；其他词使用词典释义与个人造句提示。词典释义组未全部人工拆成独立义项，人工哲理卡片优先。
- 5,358 条单词发音、89 条例句发音，本机 Microsoft Zira Desktop 美音合成；共 5,447 个 MP3。
- 阅读、听音、造句分别记录。待批改不算答错或掌握；造句词义与基础语法均正确才通过。
- 优先错句和到期复习，再加入新词；每日新词上限默认 10，可调整。连续两次答错优先插入曾答对的基础词义；刚开始没有已知词时，改做有提示的轻量热身。最近五次错三次，暂停这轮后续新词。
- 答对后的间隔依次为 1 / 3 / 7 / 14 / 30 / 60 天，答错提前至一分钟后可复习。这是可运行的初始间隔策略，不是对每个人遗忘时间的精确预测。
- 连续三个完整自然日没有学习，重新安排中断周学过的词，保留历史进度和错句。
- 考试日默认 2026-12-12，可更改。词库规模不代表以每天五分钟即可在考前完成全部掌握；按实际表现增加时间。

## 数据与隐私

所有学习记录只存本机 IndexedDB，不提供自动跨设备同步。更换手机、卸载浏览器、清除网站数据前先导出备份。浏览器可能因空间不足回收缓存，下载音频后申请持久化存储，但最终行为由系统决定。

DeepSeek 批改通过同源服务端转发；每次请求携带当前内存中的密钥，仅转发目标词、词义和句子。代码不记录或持久保存密钥与句子；不会将密钥打包进网页、备份、源代码或离线缓存。真人账号密钥尚未提供，因此自动化验证使用模拟 API，未产生真实 API 费用。

词典许可见 public/ECDICT-LICENSE.txt；提取版本、具体修订见 public/sources.json。官方大纲入口：https://cet.neea.edu.cn/html1/folder/16113/1588-1.htm 。音频生成记录见 public/audio-manifest.json。

## 开发与验证

Node.js >=22.13，npm 锁定依赖。`npm run install:ci` 安装，`npm run dev` 预览，`npm test` 验证学习逻辑与批改错误处理，`npx tsc --noEmit` 类型检查，`npm run build` 构建 Worker 与完整离线清单，`npm start` 本地运行生产构建。

构建使用 Vinext / React / Cloudflare Workers。`scripts/make-offline-assets.mjs` 必须在框架构建后运行，自动纳入最终 JS/CSS 资源并更新 Service Worker。`public/sw.js` 只缓存页面与静态资源，不缓存批改请求。部署时保留 `.openai/hosting.json` 的既有项目 ID 与私人访问权限。

不包含 Google 插件，不依赖 OpenAI API 密钥。

## 本轮更新：更有温度的练习与阅读

- 六种轻量反馈：答对、答错、暂未作答、句子已保存、完成一轮、开始学习；未作答只显示提示，不新增错误。可分别关闭语音和动画，尊重系统减少动态效果。
- 新增6条离线反馈音、14篇全文朗读（合计20个MP3，4.23 MB）。朗读支持暂停、继续，切走短文页会停止朗读。
- 14篇110–128词原创哲理短文，中英对照可开关，附关键词、四选一理解题、解析、写作短语与本地保存的阅读随笔。不是历年真题；阅读随笔不假装已获AI批改。
- 30条双语每日鼓励，按本地日期轮换。
- 词族查询覆盖5358个核心词；3728个词有已收录词族关系，共7762条关系；4271个词有独立屈折变化。区分WordNet直接派生、形容副词关联和常用同族词。关系不是额外四级词条数，也不保证穷尽所有英语派生词。新资源源自Open English Wordnet 2025（CC BY 4.0＋底层WordNet许可）与ECDICT（MIT）；详见public/family-sources.json和public/WORDNET-LICENSE.txt。
- “选择”插画、成长与习惯图解配合可暂停的6秒联想演示；联想不是词源解释。联想图片和词族短文随离线页面缓存；长朗读并入音频包。
- 既有version=1学习数据向后兼容；新偏好与阅读随笔会进入现有备份。

插画使用内置ImageGen生成，项目文件为 public/memory/choose.png。提示词：一个普通年轻人在晨光与树林之间的分岔路口停下作出选择，纸张肌理水彩风，海军蓝、鼠尾草绿与暖金色，无文字、无品牌；3:2构图，适合手机词汇联想。未调用用户的任何付费图像API密钥。

补充：未完成造句选择“下次继续”会保存到句子本的草稿页；完成一次短文答题也会记录学习日期和打卡，阅读不会被误算为停学。阅读文章选择与随笔可恢复，后台造句批改只在对应练习页显示结果动画。

## 队列与备份修复

- 断开或更换 DeepSeek 密钥会取消当前批改批次，停止发送后续句子；旧请求的迟到结果不会改写学习记录。已经发送到服务商的请求可能已经计费，取消不代表撤回计费。
- 错句已重新提交、正在等待批改时，不再反复占用造句任务；该词真正到期的认词和听音仍正常复习，完成后展示已保存的句子。
- 导入备份保留完整的未完成练习与草稿，并以暂停状态恢复；导入期间暂停旧记录写入和批改，避免旧会话覆盖恢复的数据。
- 批改队列回归检查使用模拟请求，覆盖断开、迟到结果、重新连接及不完整响应，没有调用用户付费 API。

## 初学者缓冲练习

没有答对历史时，连续两次没想起来也会安排一次缓冲：先看基础词的一个词义和已有例句，收起提示后再回忆；可以直接结束这次小练习，听音和造句自选。单纯看提示不会自动记为掌握。新增基础词替换一个原计划新词，没有新词位置时只回到接触过的词义；暂停新词规则同样适用于热身。每轮最多一次，已有答对历史则优先选择确实答对过的具体义项。

## 离线音频读取修复

完整缓存的单词、提示音和短文支持单段字节范围读取，供手机播放器续播使用；范围越界返回正确状态，多段范围或失效的 If-Range 回退完整内容。在线获取的部分音频不会被错误地当作完整文件缓存，缓存空间不足也不会阻止正常在线播放。播放器使用同源 CORS 方式请求音频。验证覆盖模拟断网和 HTTP 分段请求，尚未在用户的 OPPO 真机上复测。

## 更新中断恢复

每个版本独立准备完整离线页面和资源，核对清单及首页引用后才标记就绪；下载失败会清理未完成版本，保留原版本。更新在当前页面退出后启用，避免练习中途混用新旧内容。设置中显示“新版已准备好”时，完成当前练习后关闭所有词间页面，再打开即可切换；不用重新下载已有音频。离线就绪状态由实际控制页面的版本返回，不再借用旧版标记。测试覆盖更新中断、等待切换、资源版本不一致、重启及音频保留。

## 学习计时的保存优化

计时仍每秒显示，但只复制当轮与当天的计数，每15秒保存一次；不再每秒复制和写入整份句子历史。答题、造句草稿、短文随笔继续即时保存，暂停、切换页面、打开设置、进入后台和关闭页面时补存计时。导入备份前先保存当前状态，避免取消导入后丢失刚刚学过的时间。异常断电或系统直接杀死浏览器时，最近不足15秒的纯计时仍可能未写入；既有学习记录格式与备份保持兼容。

## 朗读切换与取消

短文开始加载时即可暂停；切换文章、离开短文页或改听单词后，旧播放请求和旧音频事件不再改变当前按钮，也不会把主动暂停误报成下载失败。同一篇暂停后继续保留播放位置，播完再听从开头开始。真实播放失败会恢复按钮并提示重试。自动鼓励不会抢占正在播放或加载的声音，关闭语音鼓励会停止当前鼓励音而不打断手动朗读。验证覆盖延迟播放、主动取消、旧事件、真实失败、继续和重播，使用模拟播放器，未替代 OPPO 真机验证。

## 联想演示的真正暂停

联想图解和文字现在共用同一条6秒时间轴。暂停保留当前画面和不足一秒的进度，继续时接着播放；第三步暂停也不会被当作已经结束。收起自身或外层词族卡片、切后台、离开页面会暂停，重新打开后由用户继续。关闭动画或系统启用减少动态效果时停止自动播放，仍可用1、2、3逐步查看静态图解。测试覆盖暂停续播、后台时间排除、第三步与完整结束的区别、手动跳步和卸载后的迟到回调。

## 词族释义校正与可信范围

修正旧词典中文释义回退到其他词性的问题：20个常见词族关联依据 OEWN 的确切目标义项修订中文，例如 knowing 的名词释义、let 关联的 letter（出租人，不能套用“信；字母”）。另720条缺少匹配词性的中文被明确标为待核对，并可展开查看原始目标义项的英文定义。保留6664条匹配词性的词典释义与358条原有人工编排内容；匹配词性不等于全库已逐义项审校。5358个核心词、7762条词族关联及原有屈折变化不变，词库学习记录与音频不变。

复现本轮校正：使用 family-sources.json 中哈希一致的 ECDICT CSV 和 OEWN2025 gzip XML，运行 `python scripts/check-family-meanings.py --ecdict <CSV路径> --wordnet <XML.gz路径>`。先执行原始词族生成器时，必须再执行这一步，以免重新引入跨词性释义。人工修订与逐义项英文证据见 scripts/family-meaning-corrections.json；校正规则测试运行 `python tests/family_meanings_test.py`。原始词典许可与来源仍适用；本轮中文短释义为原创，审校范围公开在 public/family-sources.json。
